# Onboarding-Notizen

Diese Notizen helfen neuen Mitwirkenden, schnell produktiv zu werden.

## Setup
- Repo klonen, Abhängigkeiten installieren, Tests laufen lassen.
- Die CLI-Konventionen lesen ([[reference-cli-design]]).
- Das Konfig-Schema verstehen ([[reference-config-schema]]).

## Erste Schritte
- Mit der Widget-API vertraut machen ([[project-widget-api]]).
- Einen kleinen Fix in der Deploy-Pipeline begleiten
  ([[project-deploy-pipeline]]).

## Stil
Wir bevorzugen kleine, rückbaubare Änderungen und klare Commit-Nachrichten.
Lieber früh fragen als raten ([[user-team-preferences]]).
